## Contexto

Este plan ha sido elaborado para guiar el traspaso de conocimiento de un stack completo de aplicaciones de una compañía aseguradora. El objetivo es que el equipo entrante pueda operar de forma **autónoma, segura y confiable** al término del período de transición.

## Principios rectores

- **Seguridad ante todo**: ningún acceso, credencial o dato sensible se transfiere por canales no seguros.
- **Documentar primero**: cualquier conocimiento tácito debe quedar por escrito antes de dar por cerrada una transferencia.
- **Criterios de salida explícitos**: no se pasa de fase sin validar los criterios definidos.
- **Comunicación continua**: reuniones estructuradas y canales claros durante toda la transición.
- **Sin big bang**: la responsabilidad operativa se transfiere de forma progresiva, no de golpe.

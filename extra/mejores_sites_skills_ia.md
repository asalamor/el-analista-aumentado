# Mejores sites de skills de IA

Este documento recoge una selección de los mejores sitios para aprender, practicar y aplicar habilidades de Inteligencia Artificial, especialmente IA generativa, agentes, prompting, automatización documental y uso profesional en entornos corporativos.

Conviene separar dos tipos de sitios:

1. **Sites para aprender habilidades de IA**: cursos, rutas, certificaciones, laboratorios y formación estructurada.
2. **Sites de skills/agentes reutilizables**: repositorios o marketplaces de “skills” para Claude, Codex, Cursor, agentes, workflows y herramientas de IA.

---

## Recomendación rápida

Para un perfil de análisis funcional, gestión TI, IA aplicada al ciclo de vida del software, Jira, GitHub, Markdown y generación de artefactos, el orden recomendado sería el siguiente:

| Prioridad | Site | Mejor para |
|---:|---|---|
| 1 | **OpenAI Academy** | Aprender uso profesional de ChatGPT, fundamentos de IA, productividad, trabajo con IA y certificaciones OpenAI. |
| 2 | **Microsoft Learn AI** | IA en entorno corporativo, Azure AI, Copilot, agentes, certificaciones y rutas por rol. |
| 3 | **Anthropic Learn / Anthropic Academy** | Prompting avanzado, Claude, Claude Code, trabajo con documentos, proyectos y skills. |
| 4 | **DeepLearning.AI** | Cursos prácticos de Andrew Ng sobre GenAI, agentes, RAG, prompting y desarrollo con LLMs. |
| 5 | **Hugging Face Learn** | IA open source, agentes, LLMs, modelos, despliegue y experimentación técnica. |
| 6 | **Google AI / Google AI Essentials** | Alfabetización IA, productividad y habilidades generales para usuarios de negocio. |
| 7 | **Coursera** | Certificados estructurados de Google, IBM, DeepLearning.AI, universidades y empresas. |
| 8 | **Skills Directory / SkillsLLM / Agensi** | Buscar skills reutilizables para agentes, con cautela por seguridad. |

# 1. OpenAI Academy

**Sitio:** [OpenAI Academy](https://academy.openai.com/)

Es probablemente el mejor punto de entrada si se quiere aprender IA generativa desde la fuente de ChatGPT. OpenAI la presenta como un hub para adquirir conocimientos y habilidades para usar la IA de forma efectiva, con contenido público, eventos y materiales de aprendizaje.

Además, OpenAI ha lanzado cursos de certificación vinculados a **AI Foundations** y a habilidades prácticas orientadas al trabajo real, con la idea de validar competencias aplicables profesionalmente.

## Por qué interesa

Muy útil para crear una base común en una empresa:

- Uso de ChatGPT.
- Prompting.
- IA en el trabajo.
- Automatización documental.
- Generación de artefactos.
- Capacidades generales de productividad con IA.

## Uso recomendado

Empezar por fundamentos, después productividad profesional y, finalmente, cursos orientados a construcción con IA.

---

# 2. Microsoft Learn AI

**Sitio:** [Microsoft Learn AI](https://learn.microsoft.com/en-us/ai/)

Microsoft tiene uno de los ecosistemas más fuertes para empresa: Azure AI, Microsoft Foundry, Copilot, seguridad, datos, desarrollo y certificaciones. Su hub de IA organiza el aprendizaje por roles:

- Líder de negocio.
- Perfil técnico.
- Usuario de negocio.
- Desarrollador.
- Profesional de datos.
- IT.
- Seguridad.
- Low-code.

También mantiene certificaciones como **Azure AI Fundamentals**, que evalúa conceptos de IA, machine learning, visión, NLP, IA generativa y uso de Microsoft Foundry.

## Por qué interesa

Para un entorno corporativo de seguros, Microsoft Learn es especialmente potente si la organización usa:

- Azure.
- Microsoft 365.
- Copilot.
- Power Platform.
- Seguridad corporativa.
- Gobierno TI.

## Uso recomendado

Rutas de:

- AI Fundamentals.
- Generative AI.
- Copilot.
- Azure AI.
- Foundry.
- Responsible AI.

# 3. Anthropic Learn / Anthropic Academy

**Sitios:**

- [Anthropic Learn](https://www.anthropic.com/learn)
- [Anthropic Courses](https://anthropic.skilljar.com/)

Anthropic ofrece guías, tutoriales y buenas prácticas para trabajar con Claude, incluyendo desarrollo con Claude, Claude para trabajo y prompting.

También dispone de cursos como:

- Claude 101.
- Claude Code 101.
- Formación para trabajar con Claude sobre archivos y proyectos reales.

## Por qué interesa

Claude es muy fuerte para:

- Análisis documental largo.
- Generación estructurada.
- Revisión de requisitos.
- Trabajo con Markdown.
- Generación de artefactos.
- Asistencia en código.

Para un proyecto de “analista aumentado”, es una de las mejores fuentes.

## Uso recomendado

Profundizar en:

- Prompt engineering.
- Claude Projects.
- Claude Code.
- MCP.
- Skills.
- Trabajo con documentos.

# 4. DeepLearning.AI

**Sitio:** [DeepLearning.AI Courses](https://www.deeplearning.ai/courses)

DeepLearning.AI ofrece cursos de IA fundacional y cursos cortos especializados, muchos impartidos o coordinados por Andrew Ng y expertos del sector.

Su catálogo incluye:

- Prompting.
- IA generativa.
- Agentes.
- RAG.
- Evaluación.
- Desarrollo con LLMs.
- Workflows prácticos.

Tiene cursos específicos de **Agentic AI**, orientados a construir sistemas que ejecutan flujos de varios pasos, especialmente pensados para desarrolladores con Python y conocimientos básicos de LLMs y APIs.

## Por qué interesa

Es excelente para pasar de “uso ChatGPT” a “diseñar soluciones con IA”:

- Agentes.
- Workflows.
- RAG.
- Evaluación.
- Herramientas.
- Automatización.

## Uso recomendado

Después de OpenAI, Microsoft y Anthropic, usar DeepLearning.AI para profundizar en arquitectura práctica.

# 5. Hugging Face Learn

**Sitio:** [Hugging Face Learn](https://huggingface.co/learn)

Hugging Face ofrece cursos gratuitos sobre:

- LLMs.
- Agentes.
- Reinforcement learning.
- Visión.
- Audio.
- Difusión.
- Robótica.
- Contexto para agentes de código.
- Modelos open source.

Su **AI Agents Course** es gratuito y va desde conceptos básicos hasta uso y construcción de agentes. También tiene un curso específico de agentes con guía interactiva para construir y desplegar agentes.

## Por qué interesa

Es el mejor sitio para entender la IA desde el lado open source:

- Modelos.
- Datasets.
- Agentes.
- Frameworks.
- Despliegue.
- Experimentación técnica.

Muy útil si se quieren construir capacidades internas sin depender solo de plataformas cerradas.

## Uso recomendado

Profundizar en:

- Agents Course.
- LLM Course.
- Open-source AI cookbook.
- MCP.
- Despliegue.
- Experimentación técnica.

# 6. Google AI / Google AI Essentials

**Sitios:**

- [Grow with Google AI](https://grow.google/ai)
- [Google AI Essentials](https://www.skills.google/paths/2336)

Google ofrece formación para desarrollar habilidades esenciales de IA, con cursos prácticos diseñados por expertos de Google para aplicar IA al trabajo y a la productividad.

El curso **Google AI Essentials** está pensado para personas sin experiencia previa y enseña a usar IA generativa para:

- Acelerar tareas.
- Tomar decisiones.
- Generar ideas.
- Generar contenido.
- Mejorar la productividad.

## Por qué interesa

Muy útil para perfiles de negocio, analistas, managers y usuarios no técnicos. Es menos profundo técnicamente que Hugging Face o DeepLearning.AI, pero muy bueno para adopción general.

## Uso recomendado

Formación base para:

- Equipos funcionales.
- Negocio.
- Operaciones.
- Usuarios que empiezan con IA.

# 8. Skills Directory, SkillsLLM, Agensi y marketplaces de Agent Skills

Aquí cambia el significado de “skills”: ya no hablamos tanto de aprender habilidades, sino de **descargar o instalar capacidades reutilizables para agentes de IA**.

---

## 8.1. Skills Directory

**Sitio:** [Skills Directory](https://www.skillsdirectory.com/)

Skills Directory se presenta como un directorio de skills para Claude, coding agents y workflows de IA, con énfasis en skills analizadas por seguridad frente a:

- Malware.
- Prompt injection.
- Robo de credenciales.
- Exfiltración de datos.

---

## 8.2. SkillsLLM

**Sitio:** [SkillsLLM](https://skillsllm.com/)

SkillsLLM permite explorar skills open source para:

- Claude Code.
- Codex CLI.
- ChatGPT.
- Agentes.
- MCP servers.
- Generación de código.
- CLI tools.
- Extensiones de IDE.
- DevOps.

---

## 8.3. Agensi

**Sitio:** [Agensi](https://www.agensi.io/)

Agensi se presenta como marketplace para comprar y vender skills de agentes, compatibles con:

- Claude Code.
- OpenClaw.
- Codex CLI.
- Cursor.
- Otros agentes.

Usa el estándar abierto **SKILL.md**.

---

## Advertencia importante sobre marketplaces de skills

Este ecosistema todavía es inmaduro y tiene riesgos. En este tipo de repositorios o marketplaces pueden existir riesgos como:

- Payloads maliciosos.
- Robo de credenciales.
- Backdoors.
- Exfiltración de datos.
- Prompt injection.
- Skills abandonadas o sin mantenimiento.
- Código difícil de auditar.

## Recomendación de uso

Usar estos sitios solo para inspiración o pruebas en entornos aislados.

Para empresa, especialmente en sectores regulados como seguros, lo razonable es crear un repositorio interno de skills revisadas:

- `SKILL.md`.
- Plantillas.
- Scripts.
- Prompts.
- Validadores.
- Ejemplos controlados.
- Guías de uso.
- Criterios de seguridad.

# Selección recomendada para un proyecto de análisis funcional aumentado con IA

Para un trabajo de IA aplicada al análisis funcional y generación de artefactos Agile, se puede montar este itinerario:

---

## Fase 1 — Base común

- OpenAI Academy.
- Google AI Essentials.
- Microsoft Learn: AI Fundamentals.
- Microsoft Learn: Responsible AI.

Objetivo: crear una base común de uso profesional de IA generativa.

---

## Fase 2 — Uso profesional

- Anthropic Learn: prompting.
- Anthropic Learn: Claude para trabajo.
- Anthropic Learn: Claude Code.
- Microsoft Learn: Copilot.
- Microsoft Learn: Azure AI.
- Microsoft Learn: Foundry.
- Microsoft Learn: agentes.

Objetivo: aplicar IA generativa al trabajo diario de análisis, documentación, código, revisión y generación de artefactos.

---

## Fase 3 — Construcción de capacidades

- DeepLearning.AI: agentes.
- DeepLearning.AI: RAG.
- DeepLearning.AI: evaluación.
- DeepLearning.AI: workflows.
- Hugging Face Learn: LLMs.
- Hugging Face Learn: agentes.
- Hugging Face Learn: open source.

Objetivo: entender cómo diseñar soluciones propias, no solo usar herramientas existentes.

---

## Fase 4 — Skills internas

Revisar Skills Directory, SkillsLLM y Agensi solo como inspiración.

Después, crear un repositorio propio con skills para:

- Análisis de requisitos.
- Generación de historias de usuario.
- BDD.
- Trazabilidad Jira.
- Generación de casos de prueba.
- Revisión de open points.
- Control de calidad documental.
- Generación de documentación cliente.
- Separación entre entregables del cliente y know-how interno.

---

# Conclusión

La mejor combinación no es elegir un único sitio, sino usar cada uno para una finalidad distinta:

| Necesidad | Mejor opción |
|---|---|
| Aprender IA generativa desde cero | OpenAI Academy / Google AI Essentials |
| Formación corporativa y certificable | Microsoft Learn / Coursera |
| Trabajo documental avanzado y Claude | Anthropic Learn |
| Agentes, RAG y arquitectura práctica | DeepLearning.AI |
| Open source y experimentación técnica | Hugging Face Learn |
| Inspiración para skills reutilizables | Skills Directory / SkillsLLM / Agensi |

Para una empresa que quiera construir una ventaja diferencial con IA, el camino más sólido sería:

1. Formar al equipo en IA generativa.
2. Estandarizar prompts, plantillas y criterios de calidad.
3. Crear skills internas revisadas.
4. Integrar esas skills en los procesos de Discovery y Delivery.
5. Separar claramente el know-how interno de los entregables contractuales del cliente.
